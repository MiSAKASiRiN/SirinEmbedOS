# I2C4 周期采集与 EEPROM 并发验证 · 2026-09-28

本次范围是固定 I2C4 分发、FT24C128A 分段和 LIS/SPA 等待接入。未迁移参数/HostLink/INS 持久化，未改变 IOC、生成代码、MPU、链接脚本、总线速率或生产线程数量。验证应用关闭加热与融合，BMI/LSM 和其他默认服务继续运行。故障恢复主机模型与正常硬件并发分开验收。

## 实现与检查

原 High6 / 3 KiB 回调线程改为 I2C4 唯一分发者，四个静态槽：LIS、SPA 各一个保留槽，后台两个。类内 FIFO，最多连续四个周期事务后放行等待的后台事务。64 B 单笔上限；周期/后台排队期限 20/100 ms，活动期限 10 ms。四槽完成信号量替代轮询等待，LIS/SPA 完成等待 30 ms。TX 入队复制，RX 完成由分发线程复制，保留原 512 B D3 staging。取消按设备与请求序号确认；不能确认停止时隔离总线。

FT24C128A 最终读、写及校验每段最多 32 B，写入不跨 64 B 页边界，内部写周期让出总线。阻塞/非阻塞 API 共用该策略。

- `python3 Tests/run_host_tests.py`：20 套件全部通过，见 `host-tests.log`。I2C 实际源码测试覆盖保留槽、公平性、复制时机、信号量完成、按设备取消、排队/活动期限、abort 失败隔离、迟到中断与 tick 回绕；EEPROM 状态机运行 ASan/UBSan。
- `python3 Tests/Build/check_sdk.py`：九个父项目固件、公开头、C++/TLS、配置覆盖、链接段、IRQ、heap 和第三方哈希通过，见 `sdk-check.log`。
- EEPROMBringUp Debug/Release 编译链接通过，日志同目录。现存 CMSIS `optimize` 属性警告仍在。
- Debug：D1 316928 B / 320 KiB，D2 10976 B / 32 KiB，D3 512 B / 16 KiB，Flash 253480 B。Release Flash 178856 B。DTCM 128 KiB 为静态划分全部保留，不等于运行堆已耗尽。测试固件包含 16 KiB 静态备份和 16 KiB heap 工作区。

## 板端方法

沿用用户授权的单一 GDB/J-Link 会话，H723VG / SWD 4 MHz，探针 10114514。测试前将当前完整 1 MiB Flash 与 [此前保管的完整备份](../EEPROM-20260928/firmware-before.bin) 对比，匹配。现有原始 Flash 没有匹配的带符号 ELF，不能使用旧 INS 符号解释它。

每次加载测试固件后，只先读取 EEPROM，停留 stage=1；主机保存 16 KiB 备份并核对，再显式设置 command=1。应用等待 2 秒消除主机暂停影响，连续采集 3 秒空闲基线；随后双 API 整片交叉写读、页/0xFF/高地址/末字节边界检查、非法范围检查、原内容写回和整片比对。测量窗口不设断点、不暂停 MCU。

例程专用 Normal / 2 KiB 观测线程每 1 ms 读取传感器公开快照，记录各阶段第一/最后样本时间、样本变化次数、最大样本间隔和非 READY 观测次数。样本率按 `(samples-1)/(last_us-first_us)` 计算，短阶段包括相邻阶段的首个旧样本，属于近似阶段率；`not_ready` 在此指公开状态不是 READY，区别于器件状态寄存器“尚无新数据”的正常计数。阶段间可错过一次观测，不把它当作全部传感器输出无丢样的证明。原始观测结构大小为 576 B，保存为 `continuity-*.bin`，解析见 `summary.json`。

## 结果

先测试了 32 B 读、64 B 写/校验版本：25.063 秒内 20 项检查通过并恢复，传感器无离线、总线无错误，但 LIS 整片写时约 46 Hz、最大间隔 28.988 ms，因此缩短写/校验事务。首轮原始证据保留，不作为最终实现结果。

最终全部 32 B 分段版本：`stage=6`、20 通过/0 失败、`restored=true`，总测试耗时 32.864 秒，所有阶段两传感器非 READY 观测均为 0。完整日志见 `gdb.log`。

|---|---:|---:|---:|---:|
| 空闲基线 | 95.7 | 20.002 | 16.3 | 71.295 |
| 首次整片阻塞写 | 88.9 | 20.001 | 16.3 | 75.998 |
| 首次整片异步读 | 92.8 | 20.003 | 16.3 | 70.000 |
| 第二次整片异步写 | 89.1 | 20.001 | 16.3 | 73.987 |
| 第二次整片阻塞读 | 93.1 | 20.001 | 16.3 | 74.995 |

一次整片写（包含写周期及逐段校验）约 8.19 秒，整片读取约 2.57 秒。LIS 实际采样有抖动，并非严格 100 Hz；当前取舍优先共享总线下的稳定中低频采集，EEPROM 作为偶发背景作业。

负载窗口累计新增 LIS 2951 样本、SPA 536 样本；两者错误、恢复、重初始化均未增长，结束均 READY。周期事务新增 12973 次、后台事务 4696 次，全部完成；两类错误、超时、取消、队列满均为 0，总线无恢复/隔离。运行累计最大周期排队 3349 µs、后台排队 1413 µs、后台传输 3355 µs；这些最大值包括启动及备份阶段。队列高水位 1 符合当前一个后台发起者和串行环境 worker；满槽和公平性压力另由主机测试覆盖。

最终 CFSR/HFSR 均为 0，直接读取 `xFreeBytesRemaining=93608`。I2C 3 KiB 栈扫描保留 2872 B 未触及填充值；只是本次正常路径余量，不代表故障路径最坏栈深。
