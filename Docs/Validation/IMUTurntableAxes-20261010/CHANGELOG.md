## 坐标和方法

原始BMI088映射到SDK板坐标为(x,-y,-z)，LSM6DS3为(y,-x,z)，以Board/Support/Devices/sensor_frames.c为准。每个完整分轴段使用相邻静止数据扣零偏，积分三轴角速度并按编码器正方向定向；依次拟合六种轴嵌套顺序，保留非严格正交的实际轴方向。四姿态分轴段用于辨识，末尾联动段独立核对。

令a1/a2/a3为默认姿态下各电机正向单位轴在板坐标中的表示；q是相对默认位置的实际编码器角度（弧度），Rot(a,phi)为绕a的右手旋转。当外到内为ID1→ID3→ID2时：

- b1(q)=Rot(a2,-q2) Rot(a3,-q3) a1
- b2(q)=a2
- b3(q)=Rot(a2,-q2) a3
- omega_board=b1*qdot1+b2*qdot2+b3*qdot3

轴方向矩阵J(0)=[a1 a2 a3]是默认姿态的角速度雅可比，不应直接当成精确正交安装旋转。JSON另给出最近的正交矩阵，约定电机参考系X/Y/Z分别近似对应ID1/ID2/ID3正向；该近似不能消除真实不正交/轴承摆动。

每颗IMU单独拟合，避免把两颗IMU间的安装/尺度差异混入共同真值。残差仅是本轮内部一致性，不是可溯源角度精度。没有写入EEPROM、修改SDK安装矩阵或进行陀螺比例因子/温漂校准。

revision15在phase154到位计时反复重置，未等到超时：停止该次采集、编译并烧录revision16，重新执行完整计划。revision16仅将坐标辨识专用判据改为12raw/2°每秒持续1秒，静止段仍2秒；原回默认判据和控制/保护不变。run17-reconnect为中止的辅助数据，不作为最终完整验收。run18从phase0开始完整记录180.039秒，31步均完成，最终Hold、fault0。BMI088/LSM6DS3分别180035/180034样本、无序号间断/解码错误。24个完整分轴段全部参与拟合，两个联动段独立验证。

## 使用和验证边界

JSON的home_positive_axes_board_rows每一行依次为a1/a2/a3，取转置得到默认姿态J(0)。home_positive_axes_native_rows为对应芯片原始坐标中的方向。R_board_from_motor_nearest_orthogonal和quaternion_wxyz仅是默认姿态的最近正交参考系；不要用它代替所有姿态下的J(q)。raw零位使用350/4850/5140，q按编码器差换算弧度（ID3沿允许弧展开）。

结果可用于后续运动学和IMU标定流程的初始坐标映射。联动第一段仍有约2.1～2.3°的Z积分差，不能声称完成精密外参/比例因子校准，不能把残差全部归因于某一IMU。未校准编码器绝对精度、机构弹性/间隙、轴不正交、温漂及跨轴尺度误差。本轮每颗IMU独立结果存在差异，未强行合并成共同真值。后续应在更多速度/姿态、重复往返和热稳定条件下交叉验证。

完整原始流与ELF保留build/IMUTurntable27/board/run18/rx.bin、run18.elf。正式分析脚本为Examples/IMUTurntableBringUp/calibrate_axes.py。run17及重连流是中止的辅助记录；最终结果只采用run18。
