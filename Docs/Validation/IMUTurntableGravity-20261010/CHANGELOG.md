# ID3制动与重力补偿、三轴速度质量验证（2026-10-10）

revision14仅修改示例控制：ID3正向输出斜率8000→40000raw/s，与负向对称；ID3改回算抗饱和5/s，使积分跟踪实际斜率受限输出。速度PI100/100、20ms反馈滤波保持。增加重力电压前馈3120cos(theta)+4240sin(theta)，theta是实际展开位置，以raw4200为0弧度；没有虚拟轨迹。ID1/2参数、±30000输出限制、54/27/27°/s速度目标、端点和保护规则保持。

前馈来自run14/15四个静止窗口末1秒平均承重电压，各轮拟合cos/sin两项后取平均的80%，系数取整。样本含两次默认位置、下端点和上端点；静摩擦及方向迟滞影响明显，因此这是当前转台负载的保守初值，不是力矩标定，不保证换负载仍成立。PI继续补偿残差。没有更改SDK公共API、生成代码、线程或内存布局。

增量固件构建通过；未运行主机测试。烧录run16.elf并比对.text匹配，复位后立即detach，避免运动中暂停MCU。完整运行132.283秒，三轴全部行程完成并回默认，无故障。两颗IMU各132278样本、序号无间断、解码错误0。调试器/服务器退出后的独立6秒采集仍为Hold，末次raw350/4850/5139，指令405/-176/6633，ID3继续承重；探针和CDC1均已释放。

分析口径：编码器speed_dps是100ms低通；双IMU角速度沿运动轴投影，峰值使用51ms滑动均值；巡航波动使用21ms均值减501ms趋势后的RMS，只选已进入巡航且离减速区至少3°的数据。它不是严格带通指标，也不是机械振幅。IMU观测可能包含其他轴的耦合振动；行程完成与速度质量分别评价。

## 结果与限制

用户现场反馈本轮肉眼看不到加速和抖动。数据确认ID3大幅改善，但仍不是恒速精度验收：目标27°/s，正扫/返回编码器100ms峰值75.18/118.35→35.27/34.77°/s，双IMU51ms峰值本轮39.10/38.98及37.18/36.94°/s。巡航速度误差RMS23.67/32.59→3.92/4.71°/s；输出最大仍约7364raw，没有靠提高电压上限获得改善。此次同时改变斜率、抗饱和和前馈，不能单独量化每项贡献。

ID1参数未变，目标54°/s。编码器正/返峰值58.58/59.27°/s；BMI巡航21ms速度中央90%约43.9～63.5及负向45.5～65.0°/s，存在低频起伏，双IMU一致。去501ms趋势后的波动RMS正/返3.02/2.59°/s，与旧轮3.01/2.46接近；编码器较平稳不能代表板端角速度同样平稳。尚不能区分轴间耦合、结构弹性/间隙或控制因素，不做机械故障定论。

ID2巡航较稳定：目标27°/s，编码器误差RMS0.92/1.07°/s，IMU去趋势波动约1.28/1.33°/s，与旧轮接近。但启动约0.05秒处双IMU有89.55/89.37°/s正向峰值，返回76.13/75.84°/s；51ms平滑速度超过40.5°/s约61/56ms。旧轮也有76.29/74.45°/s启动峰值，本轮并未消除；肉眼看不到不等于没有瞬态。不因本任务擅自更改ID1/2参数。
