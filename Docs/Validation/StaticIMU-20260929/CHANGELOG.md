# 手动静态 IMU 校准验证

2026-09-29，ST Arm Clang / STM32CubeCLT 1.22.0，Minimal Debug/Release。此次只修改自维护服务、公共接口、测试、协议和文档；没有 Generate、第三方修改、烧录或调试器连接。

## 行为与测试

- 上位机 CONFIG 0x09 选择 BMI088/LSM6DS3/两颗，由已有 HostCmd 每 10 ms 观察原始快照约 5 s，估计陀螺零偏；不估计任意姿态下不可分辨的加速度零偏/比例。保留有效已有加速度校准，无有效记录时使用中性值。
- 采集期间检查设备、样本新鲜性/序号、误差计数、静止统计和温漂；所有选中器件通过后才保存。沿用 Storage 单份 CRC、提交页和完整读回，保存后下次启动应用，运行中 active 不变。
- 新增算法测试使用真实 `imu_calibration.c` 和 `imu_static_calibration.c`，注入传感器/时间和记录存储替身。覆盖任意姿态、零偏均值、保存但未重启的加速度校正保留、下一次启动、运动/方差/温度拒绝、NaN/Inf、缺字段、过期/重复序号、传感器错误、加热故障、50 ms 饥饿与总超时、时钟/序号回绕、写入租约、错误上下文和单颗保存失败。
- 新增真实协议适配器测试，替换注册/执行器边界，覆盖版本/长度/mask/权限、BUSY、延迟执行、68 B 小端/float32 黄金字段、部分保存错误、状态查询和失败重新注册不改变冻结权限。
- 既有真实 Link 活动表回归在 5 s 后重试仍只执行一次、不同正文冲突、10 项满表 BUSY、重放和断连；真实 Storage/FT24C128A 模型回归继续覆盖提交撕裂和校验。新校准专项未模拟真实硬件时序，也不是全链路板测。

新增固定对象包括两颗累计器 560 B、状态副本 64 B、job 计数器 4 B、协议权限 1 B；链接间隙随构建变化。无新线程、队列、DMA 缓冲区、链接段或运行期分配；HostCmd 保持 2 KiB 栈、Low1 优先级。

采样/温控检查私有函数显式不内联，采样局部对象不会叠在 EEPROM 调用链上。Debug 校准主函数栈帧从初版 328 B 降到 104 B（Release 72 B）；观察函数帧为 224/200 B。`.su` 只是单函数编译结果，**不是完整调用链上界或实测水位**。实际 HostCmd 栈余量、调度开销和 RTOS heap 剩余量未在本轮测量，不用静态 D1 剩余代替运行期 heap。

## 板端待验收

- 在温稳和不同任意静止姿态触发命令，比较原始 gyro 均值、保存回读与重启后的校正；加速度原始值/既有系数和 INS 方向保持合理。
- 采集中移动/振动、加热阶段温漂、传感器失效、I2C/EEPROM 故障，核对具体错误、无伪成功和部分保存掩码；单份写入中真实断电单独验证。
- 在 INS、CAN 与 CDC 遥测负载下测量校准 CPU、采样间隔、HostCmd 栈水位、I2C 公平性和20 s期限；过载可明确拒绝，不能静默使用稀疏/旧数据。
- 校准中读取状态、同序号重试、CDC 断连重连：已开始工作继续、旧响应不跨会话、新主机能查询最后结果；并发 SAVE 应可返回 BUSY，不应死锁。
- 新值仅重启后进入 INS。此次成功保存表示 gyro-only 记录有效，不等于完整加速度、多温度或动态精度标定。
