## 编码器与双IMU对比

下表单位为度。IMU使用各轴运动前静止窗扣偏置、沿本次运动估计轴投影积分；这不是独立标定精度验收，不能把差值全部归因于IMU。双IMU原始数据持续记录，没有启用融合/温控或写EEPROM。

| 电机/阶段 | 编码器位移 | BMI088积分 | LSM6DS3积分 |
|---|---:|---:|---:|
| ID1 forward | 361.230 | 362.240 | 360.690 |
| ID1 return | -361.450 | -362.076 | -360.332 |
| ID2 forward | 361.274 | 360.412 | 360.237 |
| ID2 return | -361.450 | -360.383 | -359.426 |
| ID3 to_lower | -38.232 | -38.561 | -38.267 |
| ID3 lower_to_upper | 265.474 | 265.591 | 264.226 |
| ID3 return | -226.318 | -225.784 | -224.524 |

ID3首次抬升：编码器47.900°，BMI088积分向量模48.233°，LSM6DS3为48.008°。BMI088/LSM6DS3分别137773/137772样本，无序号间断、无解码错误，最大采样间隔1.072/1.111ms。
