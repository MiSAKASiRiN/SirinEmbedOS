## 2026-10-06 迁移验收阶段

截至该日，49 个 Framework 的迁入、拆分或排除已登记，主机与固件构建通过。托管任务、传感器、ADC 软件注入、CDC 背压/重连及部分 CAN/I2C 负载已有板测；当时尚未形成完整生产验收基线。

- CAN1/CAN3 与 CAN1/CAN4 的各档速率、CPU、栈余量及过载结果统一见 [CAN 历史验证](../Source/IO/CAN/CHANGELOG.md)。优化前后的固件和负载不同，不能当作严格 A/B 对照；四路同步、UART 混合与物理故障恢复不在这些短测的覆盖范围。
- 当时 Minimal Release 链接余量为 D1 73248 B、ITCM 2432 B，应用对象池固定 32 KiB。这些链接数字不是业务可以额外分配的运行期余量，默认也未周期扫描栈。
- 正常固件一分钟窗口内 LSM 为 59.895–60.723°C，INS 温稳保持 8.696 s 后再次降级，但姿态仍有效。该结果说明温稳和采样连续性需要分别验收，不能以 VALID 代替温稳合格。
- 六个 CAN 板测镜像报告身份记录 `SRNOS_STORAGE_CORRUPT (6)`，而参数加载成功、INS 未标 UNCALIBRATED；该现象不能证明整片 EEPROM 损坏，测试未写入或格式化身份区。
- LIS 在部分 2–60 s 窗口中平均 68.2–99.6 Hz，空载及恢复档同样出现；双 IMU/INS 维持 1 kHz，四传感器错误/overrun 未增长，尚无证据将其归因于 CAN 高负载。测试结束时恢复原固件。
- 当时未验项包括真实掉电、保存与控制负载并发、UART/RS485 电气时序、物理断线/卡总线、实际 USB 拔插和长期 FPU/libc/同步压力。IWDG/WWDG 监督、FatFs、MSC/DFU 属于另外的能力需求；静态 IPv4/UDP 已在 2026-10-14 接入。

## 2026-10-03 初检遗留问题

下表记录当时的审查证据；是否仍存在应按对应模块的新实现与测试复核。Release 命名工具后来已补充标准库弱符号和特定 errno TLS wrapper 的分类，不再将该历史误报列为当前缺陷。

| 当时发现 | 当时证据与限制 |
|---|---|
| 功率模型低估可能不降额 | PowerControl 在预算 50 W、实测 100 W、估算 20 W 时，主机连续五轮 scale=1，命令 10 保持 10；不能把该版本的模型限制视作实测硬上限。 |
| 长微秒忙等待的饱和风险 | Time 将 cycle 需求饱和至 UINT32_MAX；550 MHz 下 DelayUs(8000000) 已进入饱和区间，源码推导可能错过退出窗口，未在实板调用该长等待。 |
| Fault 可读 Flash 范围过宽 | 旧检查接受 0x08000000..0x09FFFFFF，而 H723 的 1 MiB Flash 末址为 0x080FFFFF；这是异常处理二次 fault 的静态风险，未主动触发硬件故障。 |
| 参数 dump 忽略输出失败 | 旧 DumpDebugPort 未检查 WriteExact，且运行源码未注册 sink，可能在未输出时返回 OK。2026-10-25 已改用正式 Logging 队列并报告失败；正常 USB 日志通路不因此被判定失效。 |
| Release 命名门禁误报 | 当时报告 13 项标准库/TLS 符号，Debug 检查通过；后续工具已细分这些编译器生成符号，仍严格检查自维护强符号。 |

## 2026-09-28 板级归属与运行验证

- Board/Support 按 System、IO、Devices、USB 管理固定接线、启动和回调；Source 保留驱动事务、寄存器时序与服务策略。固定板卡允许必要 HAL/CMSIS 依赖，不为了目录边界增加通用 backend。
- 蜂鸣器、WS2812、USB 和 MCP 的固定硬件绑定收回板级私有头；公共资源容量、总线 ID、内存属性及协议时序仍由对应接口约定。旧文件名的去向保留在[重定位表](Migration/board-support-relocations.json)，当前维护规则见 [BoardSupport](BoardSupport.md)。
- 早期启动事件屏障曾把成功返回 `0x3` 误判为失败，修复后的直接连接及软件复位未再现断言。2026-09-27 四传感器 READY、双 IMU 约 1 kHz；后续三个 10 s INS 窗口仅证明对应负载的连续性，不证明动态精度或绝对航向。
- 统计开关对照接近新增 1 个百分点的目标。循环 hook ≤1 µs、统计增量 ≤1 个百分点、Monitor 平均 CPU ≤0.1%、监测临界区 ≤10 µs 是当时的验收目标，不能用主机结果代替板测。测量口径与结果见 [Kernel](../Source/Kernel/CHANGELOG.md) 和 [SystemMonitor](../Source/Services/SystemMonitor/CHANGELOG.md)。
- ADC 单点仪表对照约 24 V/0.091 A，读得 24.641 V/0.08986 A，电压偏高约 2.67%；未逐点同步、未据此修改倍率，不构成全量程标定。
- FT24C128A 16 KiB 整片读写及备份恢复通过，400 kHz 配置下写含校验约 5.12 s、读约 1.03 s，传感器连续性短测通过；模拟边沿、断线/卡总线、真实掉电和长期负载未验。业务记录及校准的新格式须单独验证，见 [Storage](../Source/Services/Storage/CHANGELOG.md)。
