# srneos 实施与验收（计划）

本清单对应 [设计合同](DESIGN.md)，作为持续验收目标。0.1.0 已实现主机 CLI、J-Link 后端、USB/遥测/参数/RMT 与有限单会话计划，并进行主机自动化、PTY 和 wheel 安装检查；实板各项尚未验收。当前范围见 [README](README.md)，实际验证结果见 [CHANGELOG](CHANGELOG.md)，下列矩阵不表示每项都已经通过。

## 交付顺序

| 阶段 | 实现范围 | 完成门槛 |
|---|---|---|
| A 主机基础 | 可安装包、help/version/capabilities、配置、结果/错误、证据保存、doctor、host test runner | 任意 cwd 调用；配置/路径/JSON 合同；缺私有套件明确失败；不访问硬件的主机用例通过 |
| B J-Link | 探针枚举、目标识别、connect/read/verify/flash、生成读取脚本、运行状态和资源释放 | 假后端失败矩阵通过；版本对应的 Commander 模板人工审阅；实板三种连接状态、回读/保存/烧录分别验收 |
| C USB | USB 枚举、CDC 映射、独占串口、统一 SirinLink 会话、log/telemetry | 假串口分片/乱序/断连通过；实板未枚举/已枚举无协议/HELLO 成功；CDC0 安静日志正确分类 |
| D 命令与联测 | EXEC、CONTROL、参数、SirinRMT、run/cancel、反馈判据 | 无重复副作用请求；单会话遥测+发送；有界停止；应用授权后有限时实机观测 |
| E 迁移收敛 | 旧脚本改为共享模块包装、跨系统发布、离线 report/decode | 黄金向量及旧入口检查；各操作系统独立验收并声明支持范围 |

每个阶段先更新 capabilities 的实际支持项，未实现命令必须 unsupported，不返回模拟成功。A–C 构成首个连接/烧录/观测闭环；D 完成用户要求的命令与移动测试闭环，不能把完成 A 称为整套工具完成。

## 主机自动化验收矩阵

这些用例验证真实失败边界及不应产生的副作用。套件保留于本地忽略的 `Tests/Tools/CmdLineTool/` 或独立私有测试工程，不把生产工具当作可携带现场资料的目录。

| 范围 | 输入/故障 | 期望 |
|---|---|---|
| 配置 | 未知字段、NaN、负期限、地址溢出、重叠段、路径含空格 | 打开硬件前拒绝；不经 shell 拼接 |
| 选择 | 两个探针/两块相同 PID 板卡 | ambiguous_device，无自动首选 |
| 工具 | 没安装、版本不支持、供应商返回未知文本 | tool_missing/unsupported/unknown，不能误判目标离线 |
| 探针 | 不在线、OS 枚举但不可访问、被 IDE 占用 | offline/permission_denied/busy 区分；不杀 IDE、不重置目标 |
| 目标 | 探针可用但 SWD 不通、错误 ID、读保护 | target_offline/mismatch/protected；不得自动解锁/擦除 |
| 读取 | 运行 RAM、显式暂停、MMIO、部分读取 | 一致性/副作用明确；字节不足不能 successful |
| 脚本 | 请求清单含非法 name/path/地址或指令注入 | 结构化参数校验，生成固定模板；不执行自由脚本文本 |
| 镜像 | ELF 含 RAM VMA/Flash LMA、BSS/NOLOAD/多段空洞 | 正确选择 load bytes；不验证 BSS、不擅自填洞 |
| 擦除 | 镜像只覆盖扇区一部分，段外存在数据 | 明确保存恢复或显式允许，否则拒绝写入 |
| 烧录 | 下载器报成功但回读不一致/断连/超时 | compare failed/partial/unknown；不自动重烧或启动新镜像 |
| 保存 | 目录存在、并发创建同名文件、磁盘满、短写 | 不覆盖；保留部分和读取事实；非零退出 |
| 结果 | 2^64-1 时间戳/标识、非有限浮点 | 保精度字符串/null+原始位，不产生非法 JSON |
| USB | 无 USB、USB 有但 CDC 无、枚举后端缺失 | not_enumerated/missing/unknown，不混淆 |
| 日志 | 安静、乱码、二进制混入、结束无换行 | 安静不报协议失败；raw 完整保存；不往 CDC0 写 HELLO |
| HELLO | 半帧、粘包、CRC 错、旧响应、错误序号、未知版本 | 只接受匹配且完整有效的回复；保存原始数据及错误计数 |
| 协议 | HELLO OK 但 SOURCE/EXEC/IDENTITY 不支持 | 保持 link ready，能力失败单独报告 |
| 请求 | ACCEPTED 后延迟最终响应、执行后断线、缓存已过期 | 不把 ACCEPTED 当 OK；未知结果不自动换序号重做 |
| 遥测 | 部分订阅失败、0 样本、无效数据、序号缺口、epoch 变化 | 部分结果/质量判据正确；只退订本次成功订阅项 |
| 容量 | RX 高频、磁盘慢、TX 忙、进度输出阻塞 | 有界缓冲、超时/丢弃可见；运动停止路径不被文件写入永久阻塞 |
| RMT | 序号回绕、重复/乱序、多 session、两种输入切换 | 复用现有合同；不隐式 re-enable |
| RMT | move 预热、duration 到期、Ctrl-C、写异常、断线 | 预热零值，正常路径一次 ENABLE；按原类型零值/停止/失效；有界收尾 |
| RMT | DISABLE 发出但立即 INVALIDATE、反馈来自上次测试 | 留消费窗口；关联不足不判成功 |
| RMT | 另一进程抢串口或用新 session 停旧会话 | 拒绝抢占；cancel 请求原 owner 收尾；不伪称已停 |
| 清单 | 缺 suite、0 个测试、测试超时、子进程残留 | 不报 PASS；按进程组结束；逐套件结果完整 |
| 报告 | 仅 host 通过、仅 flash 通过、运动只发送成功 | evidence_level/validation 区分；无实板 PASS 冒用 |
| 中断 | SIGINT、SIGTERM、kill -9、主机重启 | 可处理信号收尾；不可处理终止留下 in_progress；不宣称都能发停止 |
| 兼容 | 旧脚本/新模块 COBS、CRC、RMT 黄金向量 | 线格式相同；明确新旧退出码/重连/收尾差异 |

## 实板验收顺序

实板动作必须使用当次授权的目标及状态，不依据旧日志推断当前连接。每步记录固件身份和最终 MCU/探针状态。

1. 不连接探针，验证 J-Link offline；连接探针但让目标调试通路不可达，验证 probe online/target offline；恢复连接验证 target online。分别留存证据，不仅手工改模拟状态。
2. 读取芯片身份、UID 和已知 Flash 段，对比独立读取结果；读取运行中的 RAM，确认没有隐式暂停/复位。显式 halt 测试另行记录时序扰动。
3. 分别验证 Flash 读成功、本地保存成功、已知镜像一致和故意不一致。检查 bin 长度/哈希及已有文件不会被覆盖。
4. 在可覆盖的测试镜像上执行烧录、回读和指定 run/halt；恢复原镜像也必须明确执行并留证据。保护/掉电等破坏性场景仅在合适测试板验证，不在生产板试探解锁。
5. 测试 USB 拔出、已枚举但不运行协议的测试固件、正常 HELLO；确认 CDC0/CDC1 映射。缺协议的固件切换是独立烧录操作，不由 connect 自动完成。
6. 记录 CDC0 日志与 CDC1 IMU/INS/SystemMonitor/SOURCE，比较逐样本、原始帧和状态计数；拔线保留部分结果。单独报告采集完整性和数据质量。
7. 验证可控的查询 EXEC 和失败响应，再验证显式授权的写命令及完成等待；不拿改参数/校准作为连接探测。
8. 父项目确认输入失效撤权、速度限幅和反馈字段后，先零输入使能，再有限时移动。采集使能、动作和停止反馈；主动中断验证收尾，物理停机条件由现场提供。
9. 在实机负载下测量持续遥测对 RMT 发送间隔及停止延迟的影响；无法保持期限就失败，不以平均频率掩盖长时间断流。
10. 在 macOS、Linux、Windows 分别验证 USB 枚举、端口占用、J-Link 输出和文件原子保存。某系统未测保持未验证。

## 版本与文档交付

每阶段更新工具 README 当前用法、模块 CHANGELOG 和根 CHANGELOG；设计稿保留待实现内容的标记。正式安装命令只能在打包安装及任意 cwd 调用通过后写入 QuickStart。

合并前检查公开差异不含个人路径、探针/板卡标识、原始捕获、私有测试代码或供应商二进制。这不要求删除本地证据，证据保留在忽略的 build/captures 目录。
