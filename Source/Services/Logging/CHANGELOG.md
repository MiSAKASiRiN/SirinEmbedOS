# Changelog

## Unreleased — 2026-11-11 配置与资源合同

- 系统预检与 UART 绑定复用 TX 能力校验；仅选中 UART 后端时使用 log_port，USB/SWO 配置不会意外绑定残留串口。
- 默认队列/池/线程栈容量使用共享私有常量；启动预算取 16 KiB 与实际池载荷、队列/TCB、线程栈及 1024 B 管理/分配余量之较大值，修正把旧 16 KiB 预留当作完整模块预算的问题。未扩大 heap；超额组合可能更早被系统校验拒绝。
- 本轮验证限定为编译，未新增或运行主机测试；未进行日志拥塞、栈水位或板端验证。
