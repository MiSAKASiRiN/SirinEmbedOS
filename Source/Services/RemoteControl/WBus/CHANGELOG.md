# Changelog

## Unreleased — 内置 Input 的 LOST 策略

- 2026-10-21：内置适配层丢弃单次 LOST 而不刷新 Input 时间戳或 epoch，保留 FAILSAFE 和串口异常失效；独立 W.Bus 解码/计数不变。更新接入说明；实帧适配与独立解码器主机回归覆盖此边界。

## Unreleased — 输入与消息

- 2026-10-21：新增逐帧回调及内置 wbus 输入来源；显式配置逐通道校准，独立 Init/Poll 仍可选。

## 2026-10-20

- 新增独立 W.BUS/S.BUS 兼容解码：16 路 11 bit 原始值、数字 17/18 和 frame-lost/failsafe 标志；仅接受经典 `0x00` 帧尾。
- 接入公开 Serial 单所有者接口，启动绑定、任务非阻塞轮询，有界处理和错误/溢出后的重同步；未接入 RemoteControl 仲裁。
- 主机 ASan/UBSan 覆盖全部 176 个数据位、所有标志组合、每个分包位置、粘包、错位恢复、配置/所有权、时间回绕、半帧超时、UART 中断续流和有界轮询。
- 父项目 EngNaviTest 使用 RF206S/USART6 上板：30.080 s 解码 2111 帧（70.180 Hz），CH1/2/4/5 连续变化，UART/解析错误与失控标志均为零；保存真实帧并加入回归。未触发实际断链/失控场景。
