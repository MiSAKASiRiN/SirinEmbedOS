# 固定 I2C4 通路

`bsp_i2c` 管理当前板 I2C4（约 100 kHz），PB7 SDA/PB8 SCL 的 HAL 初始化归 Board。公开头为 `SirinEmbedOS/IO/I2C/bsp_i2c.h`，设备保存 7-bit 地址，仅在 HAL 调用边界左移一次。支持 8/16-bit memory address。

## 调度

原 High6 / 3 KiB 回调线程改为唯一 I2C4 分发线程，提交方只入队，HAL 启动、DMA staging、完成复制、回调和恢复均由该线程负责。中断只发布结果并唤醒线程。没有新增生产线程，也没有运行期分配。

四个静态槽中，LIS `0x1E`、SPA `0x76` 各保留一个，两槽留给 EEPROM 等后台设备。同一物理地址最多一个未消费请求，不能通过多个 handle 绕过。类内 FIFO，优先周期类；连续启动四个周期事务后，若后台有排队事务则放行一个，避免存储饥饿。正在传输的事务不可抢占。

单事务限定 1..64 B。长操作由了解协议的设备驱动分段，不能在总线层任意拆寄存器操作。FT24C128A 读、写及写后校验每段最多 32 B，写入不跨 64 B 页边界；器件内部写周期等待不占总线。总线忙时，另一个设备仍可入队，不再直接收到 BUSY。BUSY 表示同地址已有请求或后台槽满，需要调用者退让重试。

周期/后台排队期限分别 20/100 ms，活动事务期限 10 ms。LIS/SPA 使用 30 ms 完成等待覆盖排队与传输。调度保证有界竞争，不保证每个样本都恰好 10 ms；板端连续性实测见 [验证记录](../../../Docs/Validation/I2C-20260928/README.md)。

## 完成与所有权

- 所有提交、等待、取消和探测均为调度器运行后的任务接口；禁止 ISR、关闭中断或锁住调度器时调用。设备 handle 由其调用者串行管理，不能由多任务无锁交错提交与取结果。
- TX 入队即复制，RX 内存保留至完成通知或取消确认。普通和现存 direct 入口统一经过复制队列及 64 B 限制；没有绕过仲裁的 DMA 入口。原始 bus acquire/release 已移除。
- 保留原 256 B TX + 256 B RX D3 非缓存 BDMA 缓冲；HAL 永远不直接访问用户 RAM。四个队列 TX 副本位于普通 RAM。
- `pending` 包含排队及传输；`wait_complete` 使用每槽完成信号量，等待期限从该调用开始计算并包含余下排队时间。超时取消对应事务，等待分发者确认后返回，保证不再访问 RX。已经完成则返回设备保留结果。
- 完成回调在分发线程执行，必须短小；可提交后续异步事务，不得等待、延时、打印或调用同步探测/取消/恢复。回调和阻塞等待混用时，不在该回调复用设备。
- 取消排队事务不影响活动设备。活动取消经 HAL abort 和 HAL/BDMA 静止确认；失败隔离总线，后续请求失败，需重启处理。取消不是 EEPROM 写入回滚。正常传输确认静止并清理挂起 IRQ 后才复用 staging。
- `device_ready` 也排队，每个试探只执行一次 1 ms HAL probe；多次尝试受调用者总期限约束，不在分发线程循环等待 EEPROM 写周期。

`bsp_i2c_snapshot_t` 分周期/后台统计接纳、完成、错误、超时、取消、队列满、最长排队与传输耗时，另有排队数、高水位和隔离状态。`cb_queued/cb_queue_overflow` 为零，因为已无独立回调队列。新增三只信号量的启动预算增加 512 B，实际任务数量、优先级、栈及 MPU/链接布局不变。

验证入口 `bash Tests/IO/I2C/run_host_tests.sh` 覆盖实际 BSP 的保留槽、公平性、复制时机、阻塞完成、按设备取消、排队/活动期限、abort 失败隔离、迟到中断和 tick 回绕。故障注入为主机模型；未做板端断线、卡 SDA 或掉电实验。
