### 从 README 归档的历史记录

`Matrix.h` 提供 C11/C++17 均可调用的 `SRNOS_MatrixF32`、绑定、乘法和转置。矩阵为 row-major，调用者持有数据；绑定不分配、不清零，乘法/转置输出必须尺寸匹配且不与输入重叠。当前沿用原三函数的计算循环，返回 `SRNOS_MATRIX_OK` 或尺寸错误，不再公开 CMSIS 类型或可被链接替换的 `arm_*` 弱符号。
